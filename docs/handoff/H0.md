## Findings for H3 (dialogue)
- **Translation works:** a line with `[ID:SOME_KEY]` plus a row `SOME_KEY,de,en` in `localization/dialogue.csv` shows English in `en` (tested). **Lines without an `[ID:…]` stay German in English.** Recommendation: give every line a static id (generated), so changing German text never breaks the English link.
- The addon's example balloon has a bug: switching the language right as a dialogue ends causes a script error in `DialogueLine.refresh()`. The custom balloon must check for a null next line.
- Balloons live under the current scene. Combat pauses and hides the level, so **never start a dialogue during combat**; use the combat log or barks instead.
- `[TEMP]` at the start of a line displays fine (tested).
