## How to try it
1. From this worktree run `powershell -ExecutionPolicy Bypass -File tools/run_h2.ps1`, or open this worktree's `project.godot` in Godot and press F6 on the desired test scene (F5 for the title flow).
2. First start: choose Deutsch/English. New game -> choose a job -> start.
3. A/D or arrows: move. Space/W/up: jump. Down+jump: drop. E / gamepad X: interact. Esc: pause. F1: test setup/scenes. F3: debug state.
4. F1 -> prepare game can recruit both companions. Use the radio at the beginning to run H0's test dialogue; set `hello_flag` there to open the later gate. Devices and examine points currently demonstrate H0's missing-text fallback until H3 supplies their dialogue.
5. Save/audio intentionally remain H0 stubs until H4. Campfire rests first and reports that saving is unavailable; it never reports a false success. Load remains disabled without a save.
6. CLI checks use the executable from AGENTS.md: `--headless --path . res://tests/test_runner.tscn`, `--headless --path . --quit-after 300`, and `--headless --path . res://scenes/ui/test_h2_flow.tscn`.
